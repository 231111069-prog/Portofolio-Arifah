Case Study // 02

Planify Web

Web-Based Task Management & Analytics Dashboard

Category Web Application / UI/UX
Target Audience Mahasiswa & Pelajar
Tech Stack PHP, MySQL, Bootstrap, Chart.js
Source Code GitHub Repository ↗
01
Executive Summary

OVERVIEW

Planify Web merupakan versi web aplikasi manajemen tugas yang dirancang untuk menghadirkan pengalaman monitoring menyeluruh bagi mahasiswa. Berbeda dengan layar smartphone yang mengutamakan kecepatan pencatatan cepat, Planify Web memanfaatkan ruang layar desktop untuk menyajikan dashboard analitik yang komprehensif, visualisasi grafik donut interaktif, serta alur pengelolaan tugas terpadu dari login hingga penyelesaian tugas.

02 // The Problem

Keterbatasan Visibilitas Tugas di Layar Kecil

Mahasiswa sering kali memiliki banyak mata kuliah dengan deadline bersamaan. Ketika hanya mengandalkan catatan ponsel, pengguna kesulitan melihat proporsi beban tugas secara makro, mengevaluasi rasio tugas yang sudah diselesaikan vs yang tertunda, dan menyusun rencana belajar intensif di meja belajar.

04 // The Solution

Dashboard Analitik Berbasis Web

Merancang aplikasi web produktivitas yang menghadirkan dashboard visual dengan indikator kartu metrik (Total Tugas, Selesai, Belum Selesai, Deadline Hari Ini) serta grafik Donut Chart (Chart.js) interaktif. Informasi disajikan secara terstruktur sehingga mahasiswa dapat menilai progres tugas hanya dalam hitungan detik.

03
Audience Profile

TARGET USER

Pengguna utama Planify Web adalah mahasiswa aktif yang menggunakan laptop atau PC sebagai perangkat kerja utama untuk pengerjaan tugas kuliah dan proyek tim.

User Persona // 01

Mahasiswa dengan Beban Tugas Tinggi

Membutuhkan gambaran keseluruhan jadwal tugas semesteran saat membuka laptop, mengelompokkan tugas berdasarkan urgensi, dan meminimalkan resiko terlambat mengumpulkan tugas kuliah.

User Persona // 02

Pelajar yang Visual-Oriented

Lebih termotivasi ketika melihat data produktivitas dalam format visual grafik dan persentase, sehingga merasa puas ketika porsi "Tugas Selesai" mendominasi diagram.

06
Visual Interface

UI DESIGN

Tampilan antarmuka nyata Planify Web yang diimplementasikan menggunakan Bootstrap 5 dan Chart.js, menyajikan informasi produktivitas dengan hierarki yang bersih dan kontras yang jelas:

localhost/planify/dashboard.php
Screenshot asli antarmuka Dashboard Planify Web
Sidebar Navigation (Dashboard, Tambah Tugas, Statistik, Setting, Logout)
Greeting Personal & Profil Pengguna ("Halo, Arifah")
4 Metric Summary Cards (Total, Selesai, Belum, Deadline)
Visual Donut Chart (Chart.js Statistik Distribusi Tugas)
07
Design Principles

UX APPROACH

UX Pillar // 01

Cognitive Load Reduction

Menghindari dashboard yang penuh informasi tidak penting. Area kerja difokuskan pada angka metrik yang berdampak langsung pada produktivitas hari ini dan visualisasi yang mudah dipindai mata dalam 3 detik.

UX Pillar // 02

Data-Driven Feedback

Memberikan kepuasan visual psikologis saat menyelesaikan tugas: status otomatis memperbarui segmen grafik Chart.js dan angka tugas selesai bertambah secara instan.

UX Pillar // 03

Responsive Grid System

Dibangun dengan Bootstrap 5 agar tata letak dashboard dapat beradaptasi secara elegan mulai dari monitor ultrawide, laptop standar, hingga layar tablet tanpa memutus alur kerja pengguna.

UX Pillar // 04

Fast Form Interaction

Formulir penambahan tugas dibuat ringkas dengan input tanggal deadline terintegrasi dan validasi langsung, memangkas waktu penginputan tugas baru seminimal mungkin.
