Case Study // 01

Planify Mobile

Mobile Task Management Application

Category Mobile App / UI/UX
Target Audience Mahasiswa
Tech Stack React Native, Expo, SQL
Source Code GitHub Repository ↗
00
Introduction

OVERVIEW

Planify merupakan aplikasi mobile yang membantu mahasiswa mencatat, memantau, dan mengelola tugas secara lebih terstruktur di perangkat smartphone.

01 // Problem Identification

THE PROBLEM

Mahasiswa sering memiliki beberapa tugas dengan deadline yang berbeda sehingga membutuhkan cara yang lebih terstruktur untuk mencatat dan memantau tugas.

02 // Digital Solution

THE SOLUTION

Planify menyediakan dashboard yang menampilkan jumlah tugas, status tugas, pencarian tugas, serta aksi untuk mengedit, menghapus, dan menyelesaikan tugas.
