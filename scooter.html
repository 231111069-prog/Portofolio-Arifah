Tourism & Scooter Rental Website

Category Web Design / UI/UX
Target Audience Tourist & Wisatawan Bali
Tech Stack HTML, CSS, JS, Responsive
Live Deployment Netlify Live Website ↗
00
Introduction

OVERVIEW

Website rental scooter yang dibuat untuk membantu wisatawan mendapatkan informasi rental scooter di area Bingin dan Uluwatu, Bali secara cepat dan transparan.

01 // Problem Identification

THE PROBLEM

Pengguna membutuhkan informasi rental scooter yang mudah ditemukan, informasi kendaraan yang jelas, serta proses booking yang sederhana.

02 // Digital Solution

THE SOLUTION

Website menyediakan informasi scooter, fasilitas, cara kerja, review, lokasi, dan akses booking/contact yang mudah ditemukan.

03 // Audience Segment

TARGET USER

Tourist dan wisatawan yang membutuhkan scooter selama berada di area Bingin dan Uluwatu untuk mobilitas liburan yang fleksibel dan aman.
